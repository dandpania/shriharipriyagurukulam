# श्रीहरिप्रिया गुरुकुलम् — Website Starter

यह एक responsive static website है। मुख्य फाइलें:

- index.html — पूरा वेबसाइट content
- styles.css — रंग, layout और responsive design
- script.js — mobile menu और current year

## चलाने का तरीका
index.html को browser में खोलें।

## Vercel पर लगाने का तरीका
इस folder को GitHub repository में upload करके Vercel में "Import Project" करें।
Framework Preset: Other / Static
Build Command: खाली
Output Directory: `.`

## आगे क्या बदलना है
1. Gallery के gradient placeholders को वास्तविक Gurukul/Temple photos से बदलें।
2. E-Library में PDF download links जोड़ें।
3. Calendar में वास्तविक पंचांग/कार्यक्रम जोड़ें।
4. Donation में सत्यापित UPI/payment gateway लगाएँ।
5. Contact में वास्तविक Google Maps location embed किया जा सकता है।
6. Logo को वास्तविक आश्रम logo से बदलें।

महत्वपूर्ण: सार्वजनिक वेबसाइट पर बैंक खाता, PAN, registration और tax-exemption details को प्रकाशित करने से पहले वर्तमान आधिकारिक दस्तावेजों से सत्यापित करें।
